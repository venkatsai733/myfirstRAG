RAG Teaching Dataset | Version 1.0

ABOUT THIS FILE
This file describes a fictional training centre named LearnTech Training Centre. All fees, schedules, contact details, facilities and policies in this file are invented for classroom teaching and RAG testing. This is not an official prospectus for any real institute. The information in this file is the source of truth for the demonstration. When information is missing, the chatbot should say that the file does not provide it.

ABOUT THE TRAINING CENTRE
LearnTech Training Centre provides practical training in programming, web development, artificial intelligence, data analysis and office tools. LearnTech Training Centre is located in Hyderabad. Courses are available to college students, recent graduates, working professionals and beginners. Training includes explanations, demonstrations, coding exercises, assignments and project work.

PYTHON PROGRAMMING COURSE
The Python Programming course is also called the Python course. The Python course fee is 12000 rupees. The Python course duration is 3 months. The Python course batch runs Monday to Friday from 5:30 PM to 6:30 PM, Indian Standard Time. The Python course is available online and offline.

The Python course is suitable for beginners. Previous programming experience is not required for the Python course. Students should know basic computer operations such as opening files, using a browser and typing. The Python course covers variables, data types, operators, input and output, conditions, loops, strings, lists, tuples, sets and dictionaries.

The Python course also covers functions, modules, exception handling, file handling, object-oriented programming and introductory database access. Students practise using Jupyter Notebook and a code editor. Python course assignments include a calculator, a marks analyser, a contact book and a file-based expense tracker. The Python course final project is a small expense tracking application. The Python course certificate requires completion of the final project and at least 75 percent attendance.

JAVA PROGRAMMING COURSE
The Java Programming course is also called the Java course. The Java course fee is 15000 rupees. The Java course duration is 4 months. The Java course batch runs Monday to Friday from 9:00 AM to 10:00 AM, Indian Standard Time. The Java course is available online and offline.

The Java course is suitable for beginners and students preparing for software development roles. The Java course covers Java syntax, variables, operators, conditions, loops, arrays, strings, methods and classes. The Java course explains encapsulation, inheritance, polymorphism, abstraction and interfaces using simple examples.

The Java course also covers collections, exception handling, file handling, introductory multithreading and database connectivity with JDBC. Java course assignments include a bank account simulation, a student marks system and a library record manager. The Java course final project is a console-based library management application. Spring Boot and React are not included in the Java Programming course; those topics belong to separate full stack courses.

DATA ANALYTICS COURSE
The Data Analytics course fee is 18000 rupees. The Data Analytics course duration is 5 months. The Data Analytics course batch runs Monday to Friday from 6:30 PM to 7:30 PM, Indian Standard Time. The Data Analytics course is available online and offline. The Data Analytics course covers Excel, SQL, Python and Power BI.

The Data Analytics course is suitable for beginners, graduates and professionals interested in analysing business data. The Data Analytics course starts with spreadsheet formulas, sorting, filtering, pivot tables and charts. SQL topics in the Data Analytics course include SELECT queries, joins, grouping, subqueries and basic window functions.

Python topics in the Data Analytics course include NumPy, pandas, data cleaning, missing values, grouping and simple visualisation. Power BI topics include importing data, relationships, basic DAX measures, report pages and dashboard design. The Data Analytics course includes descriptive statistics and introductory exploratory data analysis.

The Data Analytics course final project is a sales performance dashboard using a sample retail dataset. Students answer questions about revenue, products, regions and monthly trends. The Data Analytics course does not include advanced deep learning or training large language models. Students need basic arithmetic skills; advanced mathematics is not an admission requirement.

ARTIFICIAL INTELLIGENCE AND GENERATIVE AI COURSE
The Artificial Intelligence and Generative AI course is also called the AI course. The AI course fee is 25000 rupees. The AI course duration is 6 months. The AI course batch runs Monday to Friday from 7:30 PM to 8:30 PM, Indian Standard Time. The AI course is available online and offline.

Basic Python knowledge is required for the AI course. The AI course covers data preparation, supervised learning, classification, regression, clustering, training and testing, and model evaluation. The AI course introduces neural networks and natural language processing at a beginner level.

Generative AI topics in the AI course include tokens, tokenizers, language models, prompt design, structured outputs and embeddings. The AI course covers retrieval-augmented generation, vector databases and document question answering. The AI course also introduces tool calling, simple AI agents and human approval before external actions.

The AI course final project is a document-based question answering application. Students load a text file, split its content into chunks, create embeddings, store vectors in Chroma, retrieve relevant passages and generate answers with a small language model. The AI course uses small models and sample datasets suitable for classroom demonstrations. The AI course does not promise that generated answers will always be correct.

ADMISSION PROCESS
LearnTech Training Centre admission begins with a course enquiry and a counselling discussion. Students select a course, choose online or offline mode, complete a registration form and pay the first installment. Admission requires a name, email address, mobile number and basic education details. LearnTech Training Centre does not conduct an entrance examination for the courses listed in this file.

Students receive their confirmed timetable after admission. The batch schedules listed in this file are the schedules for this teaching dataset. A specific next-batch start date is not provided. Students should contact the training centre to confirm a future batch start date rather than assume that a batch starts on a particular date.

COURSE FEE AND INSTALLMENT POLICY
Paid course fees may be paid in two equal installments. The first installment is due at admission. The second installment is due within 30 days of the course start date. The Python course installment amount is 6000 rupees each. The Java course installment amount is 7500 rupees each. The Data Analytics course installment amount is 9000 rupees each. The AI course installment amount is 12500 rupees each.

The listed course fees include regular classes, standard digital notes, assignment review and the completion certificate when its conditions are met. A paid software subscription, external certification exam or paid cloud service is not included in the listed fees. This file does not specify taxes, discounts, refunds, cancellation charges or special offers. The chatbot must not invent a refund rule or a discount percentage.

CLASS MODES AND ONLINE ACCESS
LearnTech Training Centre offers online and offline classes. Offline classes are held in Hyderabad. Online live classes use Google Meet. Online students need an internet connection, a microphone and a device capable of joining a video meeting. A laptop is recommended for coding exercises; a phone alone is not sufficient for completing most development projects.

Students receive online class links through the registered communication channel. Online and offline students complete the same assignments for the same course. This file does not specify whether recordings are provided. The chatbot should not promise class recordings when asked.

ATTENDANCE, ASSIGNMENTS AND CERTIFICATES
Paid course certificates require at least 75 percent attendance, completion of required assignments and approval of the final project. Students submit course assignments through the learning portal. Trainers review assignments and may request corrections. A student who has not completed the final project has not yet met the certificate requirements.

Course certificates show the student's name, course name and completion date. This file does not provide a certificate verification website or certificate number format. A certificate confirms completion of the training requirements; it does not guarantee employment.

INTERNSHIP PROGRAMME
The internship duration is 3 months. The internship is free. No application fee, training fee or certificate fee is charged for the internship programme in this teaching dataset. The internship has no guaranteed stipend. Selected participants may be considered for a later paid opportunity based on performance and available positions, but selection is not guaranteed.

Internship domains include Java Development, Python Development, Data Analytics and AI and Generative AI. Internship applicants complete a registration form and wait for administrative approval. Approved interns receive portal access and assigned tasks. Interns may participate online or offline, with offline participation preferred for practical support.

Internship task submissions must include a GitHub repository link, a README file and execution screenshots where applicable. Interns must understand and explain their own work. A mentor may request revisions if a task is incomplete or the intern cannot explain the implementation. The internship completion certificate requires approved mandatory tasks, an accepted final project and a successful viva review.

STUDENT SUPPORT
Students raise technical doubts through the learning portal. A mentor replies with guidance or requests additional details. Students can request an online support appointment through Google Meet or an office support appointment. Appointment requests require confirmation; a requested time is not automatically approved.

Students should include the error message, relevant code and a description of the expected output when requesting debugging help. This file does not promise a fixed response time for every doubt. Students should never share passwords or API secrets in support messages.

OFFICE HOURS AND FACILITIES
The LearnTech Training Centre office opens at 9:00 AM and closes at 6:00 PM, Monday to Saturday. The office is closed on Sundays. Office hours are different from class timings; scheduled evening or weekend online classes may take place outside office hours.

The fictional training centre provides classroom seating, internet access during supervised lab sessions and mentor assistance. Students are encouraged to bring a laptop. Hostel accommodation is not described in this file. Hostel rent, transport services, parking charges and a full street address are not provided.

COMPUTER REQUIREMENTS
A laptop with 8 GB RAM and free storage for programming tools is recommended for introductory programming courses. For web development, analytics and introductory AI projects, 16 GB RAM is preferred. These are practical recommendations for this teaching dataset, not strict admission rules.

A dedicated GPU is not mandatory for the introductory RAG demonstration. Students can use Google Colab for small classroom experiments. Internet access is required to download packages and models on the first run. Availability and limits of external services may change and should be checked separately.
